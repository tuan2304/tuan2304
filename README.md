### Featured project

#### 🏟️ [SportArena](https://github.com/tuan2304/pickleball-booking) — real-time sports court booking platform · [Live demo](https://pickleball-booking-mu-three.vercel.app/)

Book courts (football, badminton, pickleball, tennis, basketball), pay deposits via VietQR, and open matches for other players to join — all in real time.

- **No double bookings** — enforced in Postgres with exclusion constraints; expired holds released automatically by `pg_cron`.
- **Reliable payments** — PayOS webhooks with signature verification, amount reconciliation and idempotent handling; each venue owner's PayOS keys encrypted with AES-256-GCM.
- **Security in depth** — RLS on every table, all writes through permission-checked Server Actions, SQL test suite for the policies.
- **Quality** — 150+ Vitest tests, GitHub Actions running typecheck, lint, tests and build on every push.

`Next.js 16` `React 19` `Tailwind v4` `Supabase` `PayOS` `Expo` `Vitest` `GitHub Actions`
